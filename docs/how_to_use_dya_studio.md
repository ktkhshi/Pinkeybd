## 事前に注意すること

この手順では ZMK v0.4.0 へ移行します。**これまでのキーマップは引き継げないため、DYA Studio 上で再設定が必要です。**

また、移行前にキーボードと接続端末の Bluetooth ペアリング情報を削除します。Bluetooth 接続が切れるため、作業中はキーボードを USB 接続できるようにしておいてください。

## 準備するもの

- USB データ通信に対応したケーブル
- ファームウェア書き込み用の PC
- Bluetooth 接続先となる端末
- GitHub アカウント

## 手順 1：キーボードと端末の Bluetooth 情報を消去する

1. 現在の Pinkeybd を Bluetooth 接続します。
2. キーボード上で `BT_CLR_ALL` を実行し、**キーボード側のペアリング情報をすべて削除**します。
3. 接続先の PC・スマートフォン・タブレットなどで Bluetooth 設定を開き、登録済みの **Pinkeybd** を削除（登録解除・このデバイスを削除）します。

> ![端末の Bluetooth 設定で Pinkeybd を削除する画面](/docs/images/2026-09-02%20185238.png)

## 手順 2：reset ファームウェアを書き込む

ZMK v0.4.0 に移行するため、reset ファームウェアを左右両方に書き込みます。/

1. 右手側を USB で PC に接続し、ブートローダーモードにします。
2. reset ファームウェアを右手側へ書き込みます。
3. 左手側も USB で PC に接続し、ブートローダーモードにします。
4. reset ファームウェアを左手側へ書き込みます。

## 手順 3：DYA Studio 対応ファームウェアをビルドする

1. [zmk-keyboard-pinkeybd](https://github.com/ktkhshi/zmk-keyboard-pinkeybd) を自身の GitHub アカウントへフォークします。
2. フォークしたリポジトリの **Actions** タブを開きます。
3. ファームウェアをビルドするワークフローを実行します。
4. ワークフローの完了を待ち、完了した実行結果を開きます。
5. **Artifacts**（成果物）からビルドの生成物をダウンロードし、展開します。

> ![Artifacts のダウンロード画面](/docs/images/2026-09-02%20185920.png)

## 手順 4：DYA Studio 対応ファームウェアを書き込む

展開した生成物にある、次のファイルをそれぞれ対応するキーボードに書き込みます。

1. 右手側を USB で PC に接続し、ブートローダーモードにします。
2. 右手側へ `right_trackball_studio_unlocked.uf2` を書き込みます。
3. 左手側を USB で PC に接続し、ブートローダーモードにします。
4. 左手側へ `left.uf2` を書き込みます。

> ![展開した生成物のファイル一覧](/docs/images/2026-09-01%20234412.png)

## 手順 5：Bluetooth 接続を確認する

1. 左右のキーボードの電源スイッチを **ON** にします。スイッチは親指側へスライドします。
2. 接続先の端末で Bluetooth 設定を開き、Pinkeybd と Bluetooth 接続します。
3. 接続が完了したことを確認します。キー入力と左右の分割キーボードが正常に動作することも確認してください。
4. 接続確認後、左右のキーボードの電源スイッチを **OFF** にします。スイッチは小指側へスライドします。
5. Bluetoothデバイスの追加で Pinkeybd とペアリングする

## 手順 6：DYA Studio で設定を変更する

1. **右手側**を USB で PC に接続します。
2. **左手側**の電源スイッチを **ON** にします。スイッチは親指側へスライドします。
3. [DYA Studio](https://studio.dya.cormoran.works/) にアクセスします。
4. 画面の最左の **USB接続** ボタンを押します。
5. 表示される接続先から **Pinkeybd (USB COM接続)** を選択します。
6. 接続後、キーマップやその他の設定を変更します。移行前のキーマップは引き継がれていないため、必要な設定をすべて行ってください。
7. 設定が完了したら、DYA Studio の **切断** を実行します。

> ![DYA Studio の USB接続ボタン](/docs/images/2026-09-01%20234721.png)
> ![デバイス選択画面](/docs/images/2026-09-02%20192114.png)
> ![DYA Studio の 設定画面](/docs/images/2026-09-02%20192405.png) 
> ![DYA Studio の 設定画面](/docs/images/2026-09-02%20193452.png)

以上で、Pinkeybd を DYA Studio で利用する準備と設定変更は完了です。
