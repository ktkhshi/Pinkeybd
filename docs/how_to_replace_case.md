# 1. はじめに
このドキュメントは、Piinkeybdの初期ロット用ケースから、改良版ケース（2026年2月～）への取り替えの手順を示したものです。<br>
ケースを変える場合、参照ください。

# 2. 準備
## 2.1 パーツを外す
ご利用中のPinkeybdのキーキャップとキースイッチを外します。

## 2.2 電源スイッチカバーを外す
Pinkeybdの電源スライドスイッチカバーを外します。
新ケースで再利用できますので、なくさないようにします。

## 2.3 ネジを緩める
Pinkeybdのトッププレートから留めているネジを７箇所緩めます。<br>
1本づつ緩めるのではなく、７箇所を均等に少しづつ緩めます。<br>

## 2.4 トップレートを外す
3mm～5mmほど緩めると、トッププレートが外れます。
ネジはトッププレートから外します。

## 2.5 PHコネクターを外す
基板に半田付けされているPHコネクター（メス側）を軽く押さえながら<br>
PHコネクターハウジング（オス側）を抜きます。<br>
断線しないように気をつけます。<br>

抜けたら後、基板とボトムケースを取り外し
四角の穴から通しているPHコネクターハウジング（オス側）を抜きます。

トッププレート、基板、ボトムケースに分解できたら準備が完了します。

# 3. 新しいケースへの取り替え
## 3.1 PHコネクターの挿し込み
新しいケースに基板を近づけて、電池ケースの配線の長さを調節しながら、PHコネクターハウジング（オス側）を基板のPHコネクター（メス側）に挿し込みます。<br>
ここでも、断線しないように気をつけます。

## 3.2 基板をボトムケースにはめる
手前側から斜めに傾けながら（電源スライドスイッチ用の穴に、スイッチのつまみが入るように）基板をボトムケースにはめます。

ボトムケースから生えている固定用の棒が折れないように気をつけます。<br>
設置位置が定まれば、電池ケースの導線を調整した後、基板を奥まではめます。

## 3.3 トッププレートをはめる
上からトッププレートをはめます。

## 3.4 Xiaoカバーをはめる
付属のXiaoカバーをXiaoに上からはめます。
はめるというより、載せているような状態になります。

## 3.5 電源スイッチカバーをはめる
はずしておいた電源スイッチカバーを、スイッチのつまみにはめ込みます。多少硬いことがありますがゆっくり押してはめます。

## 3.6 電池ケースをはめる
電池ケースをボトムケースの穴にはめます。
